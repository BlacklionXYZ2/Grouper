Running and waiting rows tick through one shared one-second timer (`onTick` in `lib/ui.js`; it skips ticks while the tab is hidden). The tick rewrites only the `<time>` text and its `datetime`. It runs only while the panel is open and a row is live. Finished rows show "took 4m 05s" and how long ago. Arrow keys and Home/End move between rows (spec §7).

    - The brief is the first message ("Orchestrator · brief").
    - The thread's text is the assistant's, with a model label each time the thread speaks after someone else.
    - Tool calls are compact `<details>` rows with a short argument preview, and exact input/output in monospace when opened.
    - `thread_input` from you or the orchestrator shows as a message.
    - An `ask_orchestrator` call shows as "Asked the orchestrator". The orchestrator's reply, which arrives both as a thread input and as the tool result, is shown once and labelled "Orchestrator · answer".
    - The header shows the status, device, live elapsed time, started time, tokens, and a fixed model chip: mark, id, family, provider and "fixed". There is no picker.
    - The step-in field is a composer at the bottom, with Stop thread beside it.
    - Approvals, the waiting/checkpoint card, the result and rating, files, raw events, the draft from the approval sheet's "Change" (it now keeps focus) and the wrong-conversation redirect all behave as before.
  - New `views/model-picker.js`: the composer's `<select>` is now a button (family mark plus model, or "Default model"). It opens a modal `<dialog>`: a full-height sheet at 760 px and below, a 640 × up-to-80vh overlay with a scrim above that.
    - The search field is a combobox and gets focus on open. Arrow keys and PageUp/PageDown move through the list, Enter picks, typing filters (by id, provider model, provider, kind, roles, family or maker, and free/paid/local), Escape closes and returns focus to the button.
    - "Default model" comes first, then this chat's role models, then "Other models", each grouped under provider headers from `GET /v1/providers` (id, kind, key set / no key, via device). The headers are group labels, not options.
    - Rows show the registry id, provider model, roles, Free/Paid, Local, Role default, the price per 1M when set, the context window when set, and the family.
