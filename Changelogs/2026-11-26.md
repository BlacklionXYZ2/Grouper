  - `crates/hub/src/usage.rs`:
    - `parse_free_limit` reads OpenRouter's daily free-model 429. It needs `limit_source: openrouter_free_tier_daily` or `free-models-per-day`, and takes `X-RateLimit-Limit`, `-Remaining` and `-Reset` from `error.metadata.headers`. Header names can be any case, and values can be strings or numbers. The reset can be in milliseconds or seconds.
    - The parse is defensive because the body is untrusted. Only the first 16 KiB is read and at most 64 headers. A limit has to be between 1 and 10,000,000. Remaining is capped at the limit. A reset has to fall between a day ago and a week ahead. Anything else is dropped, not guessed.
    - `free_limit_snapshot` stores the 429 as a usage snapshot: kind `requests`, window `free requests/day`, source `OpenRouter rate-limit response`, used = limit − remaining, and the reset time.
    - `Db::record_free_limit` skips the same reading within 60 s.
    - `WatchFreeLimit` and `watch_free_limit` wrap hub-side OpenRouter providers and record the snapshot when a call fails that way. The error still reaches the caller unchanged.
    - `note_thread_failure` does the same for a device thread whose failure summary carries the 429 text.
    - `Db::free_model_calls` and `free_requests_today`: Grouper's count of answered `:free` calls in the current UTC day, per OpenRouter provider.
