## 01:00 — PowerShell for run_shell on Windows, Windows risk rules for Auto

- **Why:** Auto let destructive PowerShell/cmd commands through on Windows because only Unix names were known.
- **Verified:** `cargo test --workspace` and `cargo clippy --workspace --all-targets` on Windows.
- **Open:** token matching is coarse (e.g. `git commit -m "start"` is flagged because of `start`; `net`, `move`, `format`, `sc` as arguments too); `kill`/`start` etc. are blocked as plain words; not tested on Unix/macOS.
