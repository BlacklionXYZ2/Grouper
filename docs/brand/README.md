# Grouper Brand Assets

Vectorised from [2026-11-26-app-icon.jpg](../concept-art/2026-11-26-app-icon.jpg) on a `1024×1024` viewBox using symmetric `<defs>`/`<use>` shapes and linear gradients.

## Files

- **`app-icon.svg`** — Full app icon on the deep-navy rounded-square tile (`rx="225"`, ~22% corner radius). Use for desktop/mobile app icons, installers, and PWA manifests.
- **`app-icon-1024.png`** — 1024×1024 RGBA raster export of `app-icon.svg` with transparent rounded corners.
- **`mark.svg`** — The full 13-fish school on a transparent background (same artwork as `app-icon.svg`). Use for the sidebar mark, assistant avatar, and sign-in screen.
- **`glyph.svg`** — Simplified 7-fish mark (bold centre fish + 3-per-side school arc, no tiny fins/eyes on school fish) on a transparent background, tuned to stay crisp at 16–24 px (favicons and small UI marks).
